      How well does it work?

      Evaluated on 117 held-out studies (CoronaryDominance, study-level split). Using up to four runs per study: AUROC 0.996, balanced accuracy 96%. Using just one run of each view: 94%. One RCA run alone: 94% · one LCA run alone: 88%.

      Studies are anonymised, so patient overlap between splits cannot be excluded; numbers may be optimistic on other hospitals' data.
